# ⚡ Smart Electricity Consumption Predictor

This is a machine learning web application built using **Python**, **Scikit-Learn**, and **Streamlit** to predict electricity consumption (kWh) based on environmental and operational parameters.

## 🖥️ App Interface

![Smart Electricity Consumption Predictor](screenshot.png)

## 🚀 Features
- Predicts electricity consumption accurately using a Linear Regression model.
- Interactive and user-friendly web interface.
- Instant calculation based on weather conditions, facility usage, and economic parameters.

## 🛠️ Tech Stack
- **Python**
- **Streamlit**
- **Scikit-Learn**
- **Pandas & NumPy**
